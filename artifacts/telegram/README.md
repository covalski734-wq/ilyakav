# Анимированный логотип ilyakav для Telegram

- **ilyakav-emoji.webm** — готовый файл для загрузки как видео-эмодзи: 100×100, VP9, 30 кадров/с, 3 секунды, прозрачный фон, без звука.
- **ilyakav-preview.gif** — увеличенное зацикленное превью на светлом фоне. Для загрузки в Telegram нужен WEBM выше.
- **motion-review.png** — несколько ключевых кадров на светлом и тёмном фоне.

Логотип удерживается в начале и конце цикла, между ними раскручивается в ленту и собирается обратно. Первый кадр — собранный знак, поэтому он узнаваем и без воспроизведения анимации.

## Как установить

1. Открыть официальный https://t.me/Stickers.
2. Создать набор эмодзи, выбрав видеоформат. В текстовом интерфейсе — /newemojipack, затем Video.
3. Отправить **ilyakav-emoji.webm как файл**, пройти подсказки бота, назначить обычный эмодзи и опубликовать набор.
4. Добавить набор себе и выбрать логотип в меню эмодзи-статуса рядом с именем. Для своего эмодзи-статуса нужен Telegram Premium.

Требования: https://core.telegram.org/stickers/webm-vp9-encoding

Набор не опубликован автоматически: готов только локальный файл для загрузки с вашего аккаунта.

Исходная геометрия взята из src/components/brandGeometry.ts и src/sections/ribbonSurface.ts. Экспортёр: .design/export-telegram-logo.cjs. Сам сайт при подготовке анимации не менялся.
